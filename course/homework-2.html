    Worksheet Homework 01

    Due: Friday 11th September 2026.
    🔗
    Instructions: Solutions should be written (or typed) clearly and legibly. Homeworks should be written alone without the use of AI.
    🔗

    1.

    Let \(X\) be an uncountable set. A set \(A \subseteq X\) is cocountable if its complement \(A^c\) is countable.
    🔗

    (a)

    Show that the collection \(\F\) of all subsets of \(X\) which are either countable or cocountable forms a \(\sigma\)-algebra.
    🔗
    Solution.
    The empty set \(\emptyset\) is countable (it has \(0\) elements). Hence \(\emptyset \in \F.\)
    🔗
    If \(A \in \F\text{,}\) then either \(A\) is countable, in which case \(A^c\) is cocountable, or \(A\) is cocountable, in which case \(A\) is countable. In both cases \(A^c\in \F\text{.}\)
    🔗
    To show that \(\F\) is a \(\sigma\)-algebra it remains to show that \(\F\) is closed under countable unions. Let \(\{A_i\}_{i=1}^\infty\) be a countable collection of sets in \(\F\text{,}\) and let \(A = \bigcup_{i=1}^\infty A_i\text{.}\) If every set in \(\{A_i\}_{i=1}^\infty\) is countable, then \(A\) is countable (see Proposition A.2.6). Hence \(A \in \F\text{.}\)
    🔗
    If not all sets \(\{A_i\}_{i=1}^\infty\) are countable, then at least one is cocountable. Suppose \(A_k\) is cocountable for some \(k\text{.}\) Then, using DeMorgan’s identities,
    \begin{equation*} \left(\bigcup_{i=1}^\infty A_i\right)^c = \bigcap_{i=1}^\infty A_i^c \subseteq A_k^c. \end{equation*}
    As \(A_k^c\) is countable, it follows that \(\left(\bigcup_{i=1}^\infty A_i\right)^c\) is countable, and thus \(\bigcup_{i=1}^\infty A_i\) is cocountable. Hence \(\bigcup_{i=1}^\infty A_i \in \F.\) We have thus shown that \(\F\) is a \(\sigma\)-algebra.
    🔗
    🔗
    🔗

    (b)

    Define a function \(\mu \colon \F \rightarrow \bR\) by \(\mu(A)=0\) if \(A\) is countable, and \(\mu(A) = 1\) if \(A\) is cocountable. Show that \(\mu\) is a measure on \((X,\F)\text{.}\)
    🔗
    Solution.
    It is immediate that \(\mu(\emptyset)=0\text{,}\) so we only need to show that \(\mu\) is countably additive. To this end, let \(\{A_i\}_{i=1}^\infty\) be a countable family of disjoint sets in \(\F\text{.}\) As above, if every set in \(\{A_i\}_{i=1}^\infty\) is countable, then the union \(\bigcup_i A_i\) is countable. Thus
    \begin{equation*} \mu\left(\bigcup_{i=1}^\infty A_i\right) = 0 = \sum_{i=1}^\infty \mu(A_i). \end{equation*}
    🔗
    If \(A_k\) is cocountable for some fixed \(k\text{,}\) then as shown above, \(\bigcup_i A_i\) is cocountable. Note that, since the sets in \(\{A_i\}_{i=1}^infty\) are disjoint,
    \begin{equation*} A_i \subseteq A_k^c \end{equation*}
    for all \(i \neq k\text{.}\) Thus, for \(i\neq k\text{,}\) \(A_i\) is countable. Hence
    \begin{equation*} \mu\left(\bigcup_{i=1}^\infty A_i\right) = 1 = \mu(A_k) + \sum_{i\neq k} \mu(A_i). \end{equation*}
    Hence \(\mu\) is countably additive, and therefore \(\mu\) is a measure on \((X,\F).\)
    🔗
    🔗

    2.

    Let \(X\) be a non-empty set. Show that the counting measure \(c\) on \((X,\P(X))\) defines a measure. Show that \((X,\P(X),c)\) is a complete measure space.
    🔗
    If we endow \(X\) with the discrete topology, show that \(c\) is a Borel measure on \(X\text{.}\)
    🔗
    Solution.
    As the empty set has zero elements, \(c(\emptyset)=0\text{.}\)
    🔗
    Let \(\{A_i\}_{i=1}^\infty\) be a countable family of disjoint subsets of \(X\text{,}\) and let \(A = \bigcup_i A_i\text{.}\) If \(A\) is finite, then all but at most finitely many of the sets in \(\{A_i\}_{i=1}^\infty\) are empty. Rearranging and removing the empty sets, there is an \(n\) such that \(A = \bigcup_{i=1}^n A_n\text{.}\) That is \(\{A_i\}_{i=1}^n\) is a partition of \(A\text{.}\) By the pigeonhole principle,
    \begin{equation*} c(A) = \sum_{i=1}^n c(A_i) = \sum_{i=1}^\infty c(A_i). \end{equation*}
    🔗
    If there is a \(k\) such that \(A_k\) has infinite cardinality, then \(A\) has infinite cardinality as \(A_k \subseteq A\text{.}\) Thus,
    \begin{equation*} c(A) = \infty = c(A_k) \leq \sum_{i=1}^\infty c(A_i) \end{equation*}
    and so \(c(A) = \sum_{i=1}^\infty c(A_i).\)
    🔗
    Finally, suppose every set in \(\{A_i\}_{i=1}^\infty\) is finite, but \(A\) is infinite. Then there are infinitely \(i\) such that \(A_i\) is non-empty. We have
    \begin{equation*} \sum_{i=1}^\infty c(A_i) \geq \sum_{i=1}^\infty 1 = \infty. \end{equation*}
    Thus \(c(A) = \sum_{i=1}^\infty c(A_i).\) We have thus shown that \(c\) is a measure on \((X,\P(X)).\)
    🔗
    Note that any measure on the measure space \((X,\P(X))\) is complete, since all subsets of \(X\) are in the \(\sigma\)-algebra. Alternatively, the only set satisfying \(c(A)=0\) is the empty set, and the only subset of \(\emptyset\) is \(\emptyset.\)
    🔗
    Now assume that \(X\) is endowed with the discrete topology. In this case every subset of \(X\) is open. Thus, the Borel sets \(\B(X)\) are all subsets of \(X\text{.}\)
    🔗
    Let \(K \subseteq X\) be a compact set. The sets \(\{ \{x\} \}_{x\in K}\) form an open cover of \(K\text{.}\) Since \(K\) is compact, there is a finite subcover, and so \(K\) is finite. It follows that if \(K \subseteq X\) is compact, then \(c(K) \lt \infty.\) Thus \(c\) is a Borel measure on \((X,\P(X)).\)
    🔗
    🔗
    🔗

    3.

    Let \((X,\M)\) be a measurable space. Fix \(x \in X\) and let \(\delta_x\) be the Dirac measure. Show that \(\delta_x\) is a measure.
    🔗
    Suppose \(X\) is a topological space, and \(\M=\B(X)\) is the Borel sets of \(X\text{.}\) Show that \(\delta_x\) is a Borel measure.
    🔗
    Solution.
    As \(x\notin \emptyset\text{,}\) \(\delta_x(\emptyset)=0.\)
    🔗
    Let \(\{A_i\}_{i=1}\) be a countable collection of disjoint sets in \(\M\) and let \(A = \bigcup_{i=1}^\infty A_i.\) Note that \(x \in A\) if and only if \(x \in A_k\) for some \(k\) if and only if \(x \in A_k\) for exactly one \(k\) (since the sets in \(\{A_i\}_{i=1}\) are disjoint). It follows that
    \begin{equation*} \delta_x(A) = \sum_{i=1}^\infty \delta_x(A_i). \end{equation*}
    🔗
    Suppose now that \(\M = \B(X)\text{.}\) If there is a compact set \(K\subseteq X\) such that \(K\) is not a Borel set, then \(\delta_x\) is not defined at \(K\text{,}\) and so \(\delta_x\) is not a Borel measure. However, Borel measures are almost exclusively considered in Hausdorff topological spaces.
     1 
    In fact, one usually considers locally compact Hausdorff spaces. More on this next semester.
    In Hausdorff topologically spaces, all compact sets are closed, and hence Borel (can you prove this?). Assuming that compact sets are Borel, if \(K\) is compact, then \(\delta_x(K)\) is defined and finite. Thus \(\delta_x\) is a Borel measure.
    🔗

    4.

    Let \((X,\F,\mu)\) be a measure space.
    🔗

    (a)

    Define a collection of subsets \(\F_0\) by
    \begin{equation*} \F_0 = \{A \cup B \colon A \in \F, B \subseteq C \text{ for some }C \in \F \text{ with }\mu(C) = 0 \}. \end{equation*}
    Show that \(\F_0\) is a \(\sigma\)-algebra.
    🔗
    Solution.
    As the emptyset \(\emptyset\) is in \(\F\) and \(\mu(\emptyset)=0\text{,}\) it follows that \(\emptyset \in \F_0.\)
    🔗
    Suppose \(\{E_i\}_{i=1}^\infty\) is a countable collection of sets in \(\F_0\text{.}\) For each \(i\text{,}\) we can write \(E_i = A_i \cup B_i\text{,}\) where \(A_i \in \F\) and \(B_i \subseteq C_i\) for some set \(C_i \in \F\) with \(\mu(C_i) = 0.\) Note that \(\bigcup_i A_i \in \F\text{,}\) \(\bigcup_i B_i \subseteq \bigcup_i C_i\text{,}\) \(\bigcup_i C_i \in \F\) and
    \begin{equation*} \mu\left( \bigcup_{i=1}^\infty C_i\right) \leq \sum_{i=1}^\infty \mu(C_i) = 0. \end{equation*}
    Thus
    \begin{equation*} \bigcup_{i=1}^\infty E_i = \left( \bigcup_{i=1}^\infty A_i \right) \cup \left( \bigcup_{i=1}^\infty B_i \right) \in \F_0. \end{equation*}
    🔗
    Finally, suppose \(E \in \F_0\text{.}\) Let \(A\) and \(B\) be such that \(E = A \cup B\) where \(A \in \F\) and \(B \subseteq C \) for some \(C \in \F\) with \(\mu(C) = 0.\) Then
    \begin{equation*} E^c = A^c \cap B^c. \end{equation*}
    Intersecting the above by \(X = C^c \cup C\) and noting that \(C^c \subseteq B^c\text{,}\) we get
    \begin{align*} E^c \amp= (A^c \cap B^c) \cap (C^c \cup C) \\ \amp = (A^c \cap B^c \cap C^c) \cup (A^c \cap B^c \cap C) \\ \amp = (A^c \cap C^c) \cup (A^c \cap B^c \cap C). \end{align*}
    As \(A^c \cap C^c \in \F\) and \(A^c \cap B^c \cap C \subseteq C\text{,}\) it follows that \(E^c \in \F_0.\) We have thus shown that \(\F_0\) is a \(\sigma\)-algebra.
    🔗
    🔗
    🔗

    (b)

    Define \(\mu_0\) on \(\F_0\) by
    \begin{equation*} \mu_0(A\cup B) = \mu(A) \end{equation*}
    when \(A \in \F\) and \(B \subseteq C\) for some \(C \in \F\) with \(\mu(C) = 0\text{.}\) Show that \(\mu_0\) is a measure on \((X,\F_0)\text{.}\) (You should first show that is well-defined).
    🔗
    Solution.
    We will first show that \(\mu_0\) is well-defined. Suppose \(A_1 \cup B_1 = A_2 \cup B_2\) where \(A_1,A_2 \in \F\text{,}\) and \(B_1 \subseteq C_1\) and \(B_2 \subseteq C_2\) for some \(C_1,C_2 \in \F\) with \(\mu(C_1)= 0 = \mu(C_2).\) Then
    \begin{equation*} A_1 \subseteq A_1 \cup B_1 = A_2\cup B_2 \subseteq A_2 \cup C_2. \end{equation*}
    It follows that
    \begin{equation*} \mu(A_1) \leq \mu(A_2) + \mu(C_2) = \mu(A_2). \end{equation*}
    Similarly, \(\mu(A_2)\leq \mu(A_1).\) Hence, \(\mu(A_1) = \mu(A_2).\) It follows that \(\mu_0\) is well-defined.
    🔗
    Clearly, \(\mu_0(\emptyset) = \mu(\emptyset) = 0\text{.}\) To show \(\mu_0\) is a measure, it remains to show that \(\mu_0\) is countably additive. Let \(\{E_i\}_{i=1}^\infty\) be a countable collection of disjoint sets in \(\F_0\) For each \(i\text{,}\) we can write \(E_i = A_i \cup B_i\text{,}\) where \(A_i \in \F\) and \(B_i \subseteq C_i\) for some set \(C_i \in \F\) with \(\mu(C_i) = 0.\) Note that, \(\{A_i\}_{i=1}^\infty\) is a disjoint collection of sets in \(\F\text{.}\) Thus
    \begin{align*} \mu_0\left( \bigcup_{i=1}^\infty E_i\right) \amp = \mu_0\left( \bigcup_{i=1}^\infty A_i \cup \bigcup_{i=1}^\infty B_i\right)\\ \amp = \mu\left( \bigcup_{i=1}^\infty A_i\right) \\ \amp = \sum_{i=1}^\infty \mu(A_i) \\ \amp = \sum_{i=1}^\infty \mu_0(E_i), \end{align*}
    completing the proof.
    🔗
    🔗
    🔗

    (c)

    Show that \((X,\F_0,\mu_0)\) is a complete measure space.
    🔗
    Solution.
    Suppose \(E \in\F_0\) with \(\mu_0(E) = 0.\) Then, \(E = A \cup B\) where \(A \in \F\text{,}\) and \(B \subseteq C\) for a set \(C \in \F\) with \(\mu(C) = 0\text{.}\) As \(\mu_0(E) =0\text{,}\) we also have \(\mu(A) =0.\)
    🔗
    Take any \(D \subseteq E\text{.}\) Then
    \begin{equation*} D \subseteq A\cup B \subseteq A\cup C. \end{equation*}
    Note \(\mu(A\cup C) \leq \mu(A) + \mu(C) = 0\text{,}\) and so writing \(D\) as \(\emptyset \cup D\text{,}\) we see that \(D \in \F_0.\) Hence \((X,\F_0,\mu_0)\) is a complete measure space.
